## Working with people: Loop Lab

I created Loop Lab and taught **Build Your First Agent Loop**, a hands-on workshop co-hosted by Vonage and TechWalk at Fabrik DUMBO. The problem: turn a recurring task into a bounded workflow with a result someone can check.

The browser exercise made eight decisions explicit, including evidence, permissions, budget, verification, and stop conditions. Participants could export a Markdown contract and use a starter prompt for a small manual pilot. The exercise kept production writes and scheduling outside that first run.

One participant reported adding a verifier and a stop condition to an existing Gumloop agent after the workshop. That is a specific reported change; company-wide adoption and business savings have not been measured here.
